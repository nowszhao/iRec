# iRec

macOS 菜单栏常驻的录屏与截图工具，Rust 编写。全屏 / 选区录制、截图与标注，录完截完
的东西挂在菜单栏下面的一根绳子上，随取随用。

[English](./README.md) | 简体中文

项目主页：<https://nowszhao.github.io/iRec/>

## 特性

- **录屏** — 全屏或拖拽框选的区域，HEVC 硬件编码，输出 MP4（HEVC + AAC）；画质、
  帧率（30 / 60）、分辨率（1x / 2x）可调。
- **声音** — 关闭 / 系统声音 / 麦克风 / 系统声音 + 麦克风，各占一条音轨。
- **截图** — 全屏或选区，存 PNG。
- **滚动截屏** — 框选浏览器页面或其他可访问的滚动区域，自动滚动并拼成一张 PNG，完成后恢复原滚动位置。
- **标注** — 箭头、框图、文字都能画，选中后可以挪、改大小、换颜色，写回原 PNG。
- **晾衣绳** — 录完截完的东西挂在菜单栏下面：指针停在那儿绳子才放下来，然后单击、
  双击、拖走都行。
- **安静常驻** — 没有 Dock 图标、首次启动只打开权限引导，其余操作都在菜单栏菜单里。
- **不会入镜** — 控制窗口、选区框、晾衣绳都设为 `NSWindowSharingType::None`，录制时
  绳子还会自动收起。
- **快捷键可改** — 四个动作的快捷键都能在「快捷键设置…」里重新绑定。
- **自动更新** — 自己去 GitHub Releases 看版本，点一下就换包重启。
- **命令行** — `iRec --shot`、`iRec --update`、`iRec --selftest`。

## 系统要求

macOS 13.0 及以上，需要屏幕录制权限（首次启动的权限引导会帮你打开设置，见[权限](#权限)）。
构建需要 Rust 工具链（edition 2024）与 Xcode 命令行工具。

## 安装

从 [Releases](https://github.com/nowszhao/iRec/releases) 下载对应芯片的包：

| 机型 | 包 |
| --- | --- |
| Apple Silicon（M1 / M2 / M3 / M4 …） | `iRec-<版本>-arm64.zip` |
| Intel | `iRec-<版本>-x86_64.zip` |

不确定就先执行 `uname -m`。解压后把 `iRec.app` 拖进「应用程序」。

发布包是 ad-hoc 签名（CI 里没配 Developer ID），首次打开可能被 Gatekeeper 拦住：
Finder 里右键 → 打开，或执行
`xattr -dr com.apple.quarantine /Applications/iRec.app`。

### 从源码构建

```sh
git clone ssh://git@ssh.github.com:443/nowszhao/iRec.git && cd iRec

./scripts/build_app.sh               # 构建 release → target/release/iRec.app
ARCH=x86_64 ./scripts/build_app.sh   # arm64 | x86_64 | universal
./scripts/package_release.sh         # 每个架构一个 zip + SHA256SUMS，输出到 dist/
```

默认 ad-hoc 签名每次重建都是新的代码身份，屏幕录制授权会作废；用固定证书签名可以避免：

```sh
SIGN_IDENTITY="Apple Development: Your Name (TEAMID)" ./scripts/build_app.sh
```

推送 `v*` 标签会触发 GitHub Actions 构建两个架构并发布 release。

### 签名与分发

现在 Releases 里的包是 **ad-hoc 签名、未公证**，所以别人第一次打开会被 Gatekeeper 拦住
（提示「已损坏」或「身份不明的开发者」）：要么右键 → 打开，要么执行
`xattr -dr com.apple.quarantine /Applications/iRec.app`。ad-hoc 签名每次构建都是新的
代码身份，所以更新之后屏幕录制授权也会丢。

想和其他 macOS 开源项目一样双击就能装，需要 Developer ID 签名 + 公证：

1. 加入 Apple Developer Program（$99/年）。
2. 建一个 **Developer ID Application** 证书，再建一个 **App Store Connect API key**
   （App Store Connect → 用户和访问 → 集成，角色选 Developer）。
3. 把证书导出成 `.p12`，在仓库 Settings → Secrets and variables → Actions 里配这几个：

| Secret | 内容 |
| --- | --- |
| `MACOS_CERTIFICATE` | `base64 <证书.p12>` |
| `MACOS_CERTIFICATE_PASSWORD` | 那个 `.p12` 的密码 |
| `KEYCHAIN_PASSWORD` | 任意字符串，CI 里临时钥匙串用 |
| `DEVELOPER_ID_APPLICATION` | `Developer ID Application: 你的名字 (TEAMID)` |
| `APPLE_API_KEY_ID` / `APPLE_API_ISSUER` / `APPLE_API_PRIVATE_KEY` | API key（`.p8`，base64） |

4. 之后照常打 `v*` 标签：工作流会用 hardened runtime 签名、`notarytool` 公证、附票据，
   再用 `spctl` 复核一遍，release 说明里的安装文案也会自动换成「已公证，双击打开」。

自己检查某个包：

```sh
./scripts/check_signature.sh target/release/iRec.app   # Gatekeeper 结论 + 票据
```

## 使用

| 快捷键 | 作用 |
| --- | --- |
| `⇧⌘R` | 开始 / 停止全屏录制 |
| `⇧⌘E` | 进入区域框选（录制中再按一次停止） |
| `⇧⌘S` | 截取全屏 |
| `⇧⌘A` | 截取选区（没框选过就先框一次） |
| `⌘Q` | 退出（先写完当前文件） |

点菜单栏图标可以截图、录制或展开晾衣绳。录制过程中，原来的录制入口会显示停止操作和计时。
「设置…」（`⌘,`）集中管理声音、画质、帧率、分辨率、保存位置、晾衣绳和更新。再次打开应用也会显示设置窗口。

设置窗口里的「快捷键…」可以改任意一个：按下新组合即可，
`⌫` 清除，`Esc` 取消。新组合要带 `⌘` / `⌥` / `⌃` 之一，一个组合只给一个动作。

框选时选区内保持原始亮度，拖完后按 Enter 或点确认按钮，Esc 取消。截图选区另有「截图并标注」，只对本次截图打开编辑器。
录制选区确认后留在屏幕上，旁边有控制条：拖它整体移动，拖右下角圆点改大小，
控制条上的「截屏」和「开始录制」就在手边。录制中改区域对当前视频不生效，下次才生效，
这样画面不会跳。

滚动截屏时，先切到目标应用，再从 iRec 菜单栏选择「滚动截图…」，框选并确认页面内容（不要选浏览器工具栏）。iRec 会自动滚动采集；也可在菜单中选择「完成滚动截屏」提前结束，或选择「取消滚动截屏」放弃。完成后页面停留在结束位置；取消时会恢复开始时的滚动位置。开始采集时指针会先移到选区中央一次，之后由你控制：鼠标移出选区会自动暂停，移回选区继续；选区保持边框，选区外显示实时长图预览和已拼接屏数。按 Esc 或点预览浮窗的「取消」可放弃。采集结束后可拖动长图上下边界裁剪，再点「保存裁剪」；短页面、拼接中断或达到采集上限时，也会保留已有画面供裁剪。此功能需要「屏幕录制」权限；开启「辅助功能」可使用滚动位置检测并更准确地恢复位置，没有该权限时会按画面变化继续采集。辅助功能权限位于「系统设置 → 隐私与安全性 → 辅助功能」。

## 截图与标注

截图存为 `iRec-shot-年月日-时分秒.png` 并挂到晾衣绳上。单击卡片打开原生预览，再点「标注」进入编辑器；
长截图可按宽度预览并纵向滚动。截图和录屏完成后会自动复制到剪贴板；只有点击选区中的「截图并标注」才会打开标注页。
卡片的圆角和阴影仅用于界面，导出的 PNG 保持原始尺寸。

| 操作 | 说明 |
| --- | --- |
| 箭头 / 框图 | 拖出来即可，画完自动回到选择工具，方便马上挪 |
| 文字 | 在图上点一下，输入，回车确认 |
| 选择 | 点一下标记选中，拖着走就能挪 |
| 改大小 | 拖白色手柄：箭头两端、框图一角、文字末端 |
| 颜色 | 选中后点颜色即可改 |
| `⌫` / 撤销 | 删掉选中标记 / 去掉最后一个 |
| `⌘↩` / `Esc` | 保存（覆盖原 PNG，尺寸分辨率不变）/ 放弃 |

系统自带的 Markup 是分享服务，不少机器上拉不起来，所以 iRec 自己做了一套。

## 晾衣绳

录完的录屏和截图挂在菜单栏下面的一根绳子上，第一帧带播放键，用夹子夹着。

绳子长度随内容数量收拢，默认收在屏幕上方：只在 iRec 图标附近停留 0.25 秒才展开，离开 0.5 秒收回；
新捕获会展示 2.5 秒，录制期间收起。打开预览或拖拽时保持展开。卡片通过错落吊线悬挂在下垂弧线上，随指针轻摆，静止时不周期摆动，支持系统「减少动态效果」。

| 操作 | 结果 |
| --- | --- |
| 单击 / 双击卡片 | 原生预览 / 用默认应用打开 |
| 拖到别的 App、文件夹 | 对方拿到文件，卡片照样挂着 |
| 拖到 Dock 废纸篓 | 文件进废纸篓，卡片下绳 |
| 点叉 | 移除卡片，保留文件 |
| 右键 / 预览中的「更多」 | 打开、在访达显示、移除卡片或移到废纸篓 |
| 菜单主动展开后按 ← / →、空格或 Enter | 选择卡片、打开预览（Esc 收起） |
| 预览中 `⌘C` / `⌘E` / `Esc` | 复制 / 标注图片 / 关闭预览（视频用空格播放或暂停） |

卡片只在手动取下或「清空晾衣绳」时离开绳子：拖到别处、甚至文件被别的程序删掉，
卡片都照样挂着。绳上最多挂 8 个。

动效创意来自 [Tendedero](https://github.com/alejandrobujan/tendedero)（MIT），
用 AppKit 手绘加自己积分的弹簧在 `src/line.rs` 里复刻。

## 设置与自动更新

设置（保存位置、声音来源、画质、帧率、分辨率、晾衣绳开关）存在 `NSUserDefaults` 里。
默认保存到桌面，录屏文件名 `iRec-年月日-时分秒.mp4`。

启动 5 秒后静默查一次更新，之后每 24 小时一次。有新版本时菜单出现
「↑ 发现新版本 v0.1.x，点此更新」，点一下就下载对应芯片的包、换掉 `iRec.app` 并重新打开；
「检查更新…」手动查，「启动时检查更新」可以关掉，命令行是 `iRec --update`。
换包后签名变了，屏幕录制权限可能要重新授权一次。

## 权限

首次启动会打开权限总览。点击「开始拖拽设置」或某一项的「拖拽设置…」，
iRec 会打开对应的系统设置页面，并在旁边显示带有产品图标的拖拽浮窗。

1. 把浮窗中的 **iRec 图标**拖入系统设置的应用列表。录屏权限请使用上方的
   「录屏与系统录音」列表，不是下方的「仅系统录音」。
2. 按系统提示确认开关或身份验证。若列表中已有当前 iRec，确认对应开关即可。
3. iRec 实时检查实际权限状态，检测到开启后自动引导下一项。拖入成功本身不会被当成已授权。

设置后仍显示待设置时，点击浮窗中的「重启后检查」；重启后会回到当前权限步骤。
可以随时通过设置中的「权限设置…」重新打开引导。

普通截图、录屏只需要录屏权限；自动滚动长截图还需要辅助功能权限。缺少所需权限时，
捕获入口会先打开对应的拖拽引导，不再先触发旧的屏幕录制或辅助功能申请流程。
系统权限开关与验证仍由用户确认，应用不能代为开启。

麦克风是独立的系统权限，macOS 不支持拖入应用来添加麦克风授权；仅选择麦克风录制时按系统提示确认。

两种情况会让授权看起来失效：重新编译（ad-hoc 签名每次都是新身份）和改签名或
bundle id（`com.nows.irec`）。

## 命令行

```sh
iRec --shot [--region x,y,w,h] [--scale 2] [--out <dir>]   # 截图（y 从底部算起）
iRec --update                                              # 检查更新
iRec --selftest --seconds 5                                # 不启界面直接录一段
```

`--selftest` 还支持 `--fps`、`--scale`、`--out`、`--audio off|system|mic|both`、`--region`；
`SCREEN_REC_DEBUG=1` 可以打开采集诊断。日志在 `~/Library/Logs/irec.log`。

## 输出

| 项目 | 值 |
| --- | --- |
| 封装 / 编码 | MP4，HEVC 视频（硬件）+ AAC 128 kbps / 48 kHz 立体声 |
| 采样 | YUV420 |
| 默认值 | 均衡画质、30 fps、2x（Retina 像素）、系统声音开 |
| 实测体积 | 3456×2234、均衡画质下约 21 MB / 分钟 |

每 5 秒刷一次 movie fragment，即使崩溃留下的文件也能播，不会变成打不开的空壳。
停止录制在后台线程收尾，退出时会把正在录的文件写完。

## 已知限制

- 只录主显示器。
- 发布包未公证。
- 录制中改选区对当前视频不生效。
- 拖放目标如果把文件移走，卡片仍指向旧路径。
