iRec

菜单栏里的屏幕录制工具。⇧⌘R 全屏、⇧⌘E 选区，录完的视频不躺在文件夹里吃灰——它挂在菜单栏下面的一根绳子上，随取随用。

该有的都在，不该有的不占地方

菜单栏里一个图标搞定录制、截图、标注、画质和权限；自己的窗口不会被录进视频。

全屏 / 选区录制

拖拽框选，松手后选区框留在原地，可以拖动、改大小，控制条上直接开始或截屏。录制中改区域不会让视频跳变，新区域下一次生效。

四档声音

关闭 / 系统声音 / 麦克风 / 系统声音 + 麦克风，各占一条独立音轨；麦克风用 AVAudioEngine 采集 48 kHz 立体声。

HEVC 硬编，文件很小

YUV420 采样 + 硬件编码，画质、帧率（30 / 60）、分辨率（1x / 2x）都能调，输出 iRec-年月日-时分秒.mp4。

截图与标注

⇧⌘S 截全屏、⇧⌘A 截选区，存 PNG 后可以直接在 iRec 里画箭头、框图、打字，写回原图尺寸不变。

晾衣绳

录完的视频和截图挂在菜单栏下面：单击在访达中显示，拖到别的 App 或文件夹就送过去，点叉才下绳。

不打扰

静默常驻，没有 Dock 图标、启动不弹窗；控制窗口、选区框、晾衣绳都设为 NSWindowSharingType::None，不会入镜。

自动更新

启动后自己去 GitHub Releases 看一眼，有新版本时菜单栏多一行提示，点一下下载换包重新打开；也可以关掉。

命令行也能用

iRec --shot 直接截图，--region / --scale / --out 可选；--update 查更新，--selftest 做无界面自测。

设置记得住

保存位置、声音来源、画质、帧率、分辨率都存在 NSUserDefaults 里，重启后照旧。

录完就挂起来，别再翻文件夹

第一帧加个播放键，用夹子夹着，从你刚录的那块区域飞上来。指针在菜单栏停留 0.25 秒绳子才滑下来，离开 0.5 秒自己收回去；刚录完也会露脸 2.5 秒。

卡片只在手动删除或「清空晾衣绳」时离开绳子：拖进文件夹、对话框，甚至文件被别的程序删掉，卡片都照样挂着。绳上最多挂 8 个，多了最旧那个自己掉下去。

截完图，顺手就标完

⇧⌘S 截全屏、⇧⌘A 截选区（没框选过就先框一次，松手即截），框选控制条上也有「截屏」。截完直接进标注，不用再开别的软件。

箭头 / 框图 / 文字

选中后拖一条线、一个矩形，或者点一下打字。画完自动回到选择工具，方便马上挪位置。

挪得动，改得了大小

点一下标记选中它，拖着走就能挪；拖白色圆点手柄改大小——箭头两头各一个，框图右下角一个，文字右端一个。

写回原图

⌘↩ 完成即覆盖写回原 PNG，尺寸和分辨率不变，晾衣绳上的缩略图随即更新；Esc 放弃。⌫ 删选中标记，撤销去掉最后一个。

快捷键与命令行

⇧⌘R开始 / 停止全屏录制
⇧⌘E进入区域框选；录制中按一次停止
⇧⌘S截取全屏
⇧⌘A进入区域框选，松手即截图
⌘Q退出（退出前会先写完当前文件）
 
iRec --shot                      # 截一张全屏
iRec --shot --region 0,0,1280,800 --scale 2
iRec --update                    # 检查并更新
iRec --selftest --seconds 5      # 无界面自测

命令行走的是同一套代码：--shot 存 PNG 到保存位置，--update 从 GitHub Releases 拉对应芯片的包换掉自己。

下载

当前版本 v0.1.4，需要 macOS 13.0 及以上。不确定芯片就先在终端执行 uname -m。

Apple Silicon iRec-0.1.4-arm64.zip M1 / M2 / M3 / M4 … Intel iRec-0.1.4-x86_64.zip x86_64 Mac
  1. 解压后把 iRec.app 拖进「应用程序」。
  2. 首次打开若被 Gatekeeper 拦住：Finder 里右键 → 打开，或执行 xattr -dr com.apple.quarantine /Applications/iRec.app。
  3. 第一次录制时按提示给「屏幕录制」权限；若设置里已勾选却仍录不了，用菜单里的「申请 / 检查屏幕录制权限」，弹窗第一个按钮就是重启 iRec。

包是 ad-hoc 签名（CI 里没配 Developer ID），所以没有公证，跨机器分发需要上面那一步解除隔离属性；每次换包签名身份都会变，屏幕录制权限可能要重新授权一次。校验用同目录下的 SHA256SUMS。已经装了旧版本？不用手动下——打开 iRec，菜单栏会提示新版本，点一下就自动换包。

常见问题

设置里已经勾了屏幕录制权限，为什么还是录不了？

macOS 的授权只对之后启动的进程生效，勾完要完全退出再打开一次。另外开关里可能记着上一个签名（重新编译或换包后很常见）：去系统设置把 iRec 的开关关掉再打开一次，列表里有多条就全部打开。菜单里的「申请 / 检查屏幕录制权限」会给出结论，弹窗第一个按钮就是「重新启动 iRec」。

为什么每次更新或重新编译都要重新授权？

默认打包是 ad-hoc 签名，每次构建都是新的代码身份，系统会当成新 app。用固定的开发者证书签名就不会失效：SIGN_IDENTITY="Developer ID Application: …" ./scripts/build_app.sh，TeamIdentifier 稳定后授权一直有效。

录屏会把我自己的窗口录进去吗？

不会。控制窗口、选区框和晾衣绳窗口都设为 NSWindowSharingType::None；录制期间晾衣绳还会自动收起来，不挡视线。

录好的文件存在哪？

默认 ~/Desktop，文件名 iRec-年月日-时分秒.mp4，截图是 iRec-shot-年月日-时分秒.png。菜单栏「选择保存位置…」可以改，设置会持久化。

系统自带的 Markup 不能用吗？

Markup 是注册在分享服务里的，不少机器上拉不起来，所以 iRec 自己做了一套标注：箭头、框图、文字、四种颜色，选中后能挪能改大小，⌘↩ 写回原图。

它一直在后台跑吗？

是的，但很安静：只在菜单栏显示一个图标，没有 Dock 图标、启动不弹窗。退出用菜单里的「退出」。自动更新默认启动后静默查一次、之后每 24 小时一次，也可以关掉。
