能做什么

录屏、截图、标注三件事，都在菜单栏那个图标里。

录屏

⇧⌘R 录全屏，⇧⌘E 框选区域；选区框留在原地，可以拖、可以改大小。输出 HEVC + AAC 的 MP4，系统声音与麦克风可选。

截图

⇧⌘S 截全屏，⇧⌘A 框选截图（松手即截）；选区控制条上也有「截屏」。存 PNG，自己的窗口不会拍进去。

标注

截完直接在 iRec 里画箭头、框图、打字；选中后能挪位置、改大小、换颜色。⌘↩ 写回原图，尺寸不变。

录完截完，都挂在菜单栏下面

指针在菜单栏停留 0.25 秒绳子滑下来，离开 0.5 秒自己收回去；刚录完会露脸 2.5 秒。绳上最多 8 个。

单击 / 双击在访达中显示 / 用默认播放器打开
拖到别的 App、文件夹送一份过去，卡片照样挂着
点叉 / ⌥ + 点叉取下卡片；⌥ 连文件一起进废纸篓

卡片只在手动删除或「清空晾衣绳」时下绳。动效创意来自 Tendedero（MIT）。

  1. 解压后把 iRec.app 拖进「应用程序」。
  2. 被 Gatekeeper 拦住就右键 → 打开，或执行 xattr -dr com.apple.quarantine /Applications/iRec.app。
  3. 第一次录制时给「屏幕录制」权限；已勾选却录不了，用菜单里的重启按钮。

包是 ad-hoc 签名、未公证，换包后权限可能要重新授权一次；校验用 SHA256SUMS。装了旧版本不用手动下——iRec 会提示新版本。命令行：iRec --shot 截图、iRec --update 查更新。

常见问题

权限已经勾选了，为什么还是录不了？

授权只对之后启动的进程生效，勾完要完全退出再打开一次；开关里可能记着上一个签名，关掉再打开一次。菜单里「申请 / 检查屏幕录制权限」的第一个按钮就是重启 iRec。

为什么每次更新都要重新授权？

默认打包是 ad-hoc 签名，每次换包都是新的代码身份。用固定的开发者证书签名就不会失效：SIGN_IDENTITY="Developer ID Application: …" ./scripts/build_app.sh。

文件存哪？会不会把自己的窗口录进去？

默认存桌面，iRec-年月日-时分秒.mp4 / iRec-shot-年月日-时分秒.png，菜单栏「选择保存位置…」可改。控制窗口、选区框和晾衣绳都设为 NSWindowSharingType::None，不会入镜。
